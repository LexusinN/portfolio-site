# Практическая работа — Раздел: HTML, SCSS

## Что реализовано

### 1. Семантическая HTML-разметка
Использованы семантические теги:
- `<header>` — шапка сайта с навигацией
- `<nav>` — навигационное меню
- `<main>` — основной контент
- `<section>` — секции страницы
- `<article>` — карточки навыков и проектов
- `<figure>` — изображение в секции "О себе"
- `<address>` — контактная информация
- `<footer>` — подвал сайта
- `<button>` — кнопки с `aria-label` для доступности

### 2. SCSS препроцессор
- **Переменные** — цвета, тени, отступы, радиусы
- **Вложенность** — вложенные селекторы для читаемости
- **Миксины** — `flex-center`, `flex-between`, `responsive-breakpoint`, `gradient-bg`, `button-base`
- **@media запросы** — адаптивность через миксин
- **Анимации** — `@keyframes float` для фона героя

### 3. Интерактивные элементы (3+)

#### А. Мобильное меню (гамбургер)
- Кликабельная кнопка гамбургера
- Анимация трансформации в "крестик"
- Выпадающее меню на мобильных устройствах

#### Б. Анимация навыков при скролле
- `IntersectionObserver` отслеживает появление секции
- Progress-бары заполняются при прокрутке
- Данные уровня навыков хранятся в `data-level` атрибуте

#### В. Валидация контактной формы
- Валидация в реальном времени при blur
- Проверка имени (мин. 2 символа)
- Проверка email (regex)
- Проверка сообщения (мин. 10 символов)
- Счётчик символов для textarea
- Визуальная индикация (зелёная/красная рамка)
- Имитация отправки с disabled состоянием кнопки

#### Г. Кнопка "Наверх"
- Появляется при прокрутке > 400px
- Плавная прокрутка наверх
- Hover-эффект

### 4. Адаптивность
- **Desktop** (> 768px) — полная версия с sidebar
- **Tablet** (≤ 768px) — гамбургер-меню, одноколоночная сетка
- **Mobile** (≤ 480px) — компактные кнопки, 2 колонки навыков

## Запуск

### Открыть в браузере
Просто откройте файл `index.html` в браузере.

### Перекомпиляция SCSS
```bash
npm run build        # одноразовая компиляция
npm run watch        # автоматическая компиляция при изменении
```

## Технологии
- **HTML5** — семантическая разметка
- **SCSS** — препроцессор CSS
- **JavaScript (ES6+)** — DOM-манипуляции, IntersectionObserver
- **CSS3** — анимации, flexbox, grid, media queries
